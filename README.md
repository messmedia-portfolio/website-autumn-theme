# Portfolio Website

A personal HTML and CSS website with a tiny bit of JavaScript. Build with vite and hosted via GitHub pages.

```
git config --global credential.helper store

ssh-keygen -t ed25519 -C "user@domain.tld"

eval "$(ssh-agent -s)"

ssh-add ~/.ssh/id_ed25519

cat ~/.ssh/id_ed25519.pub
```
